# definitely-maybe-probably-not-work

A gag-gift site: word search, I Spy, and Pac-Prof. Static HTML, no build step.

Run locally: open `index.html`.

Host free: push this folder to a GitHub repo, then Settings > Pages > Deploy from branch `main` / root.

Placeholders to swap: `Pacheco` in `index.html`, word banks in `wordsearch.html`, scene items in `ispy.html`, labels/excuses in `pacman.html`.
